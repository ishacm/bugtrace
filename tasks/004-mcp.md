# TASK 004 — Repository MCP Tools

## Read first
- `docs/MCP.md`
- `docs/ARCHITECTURE.md`

## Goal
Expose safe read-only repository capabilities through an MCP server.

## Implement MCP tools
- `list_directory`
- `search_code`
- `read_file`
- `find_symbol`
- `git_log`
- `git_show`
- `git_diff`
- `list_test_files`

## Constraints
- tools operate only against an explicit investigation workspace.
- no arbitrary shell tool.
- bounded output and timeouts.
- `read_file` maximum 300 lines.
- `search_code` maximum result limit.
- typed success/error responses.

## Client
Add a thin application-side MCP client wrapper usable later by LangGraph nodes.

## Tests
- every tool against fixture repo.
- path traversal rejected.
- line limits enforced.
- missing files return typed error.
- no mutation occurs.

## Acceptance criteria
A small integration test can start/connect to the MCP server and retrieve real repository evidence.
